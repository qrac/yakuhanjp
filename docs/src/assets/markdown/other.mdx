### OGP・GAME

CSS のようなフォールバック機能が使えない OG 画像生成やゲーム開発には、YakuHanJP を元の Google フォントに組み込んだマージフォントを使用してください。

1. [リリースの ZIP（v5.0.0）](https://github.com/qrac/yakuhanjp/releases/download/5.0.0/YakuHanJP_v5.0.0.zip)をダウンロードして展開
2. `merged` フォルダーから必要な書体・ウェイトの OTF または TTF を選択
3. 使用環境に配置してパスを設定

例: `node-canvas` を使用した OG 画像生成の実装例は [Playground](https://github.com/qrac/yakuhanjp/blob/main/playground/canvas/src/canvas.ts) にあります
